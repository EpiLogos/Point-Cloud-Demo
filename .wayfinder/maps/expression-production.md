## P2 — shared editor quality

## P3 — concurrent corpus production

Default isolation is the ordinary shared checkout/direct file output. Do not create worktrees merely for Profiles, HTML, JSON, captures or other disjoint generated artifacts. Use isolation only if shared code must be edited concurrently.

## P4 — practice return

As corpus artifacts accumulate, keep material observations linked to actual examples/counterexamples. Route reusable findings back through the accepted Ta-Onta/Aletheia/Epii Skill/Method path. Do not define new runtime Agent roles here.
